# MyManDev AI Workspace

Local-first multi-agent development workspace for MyManDev.

This project coordinates developers, repositories, AI agents, permissions, tasks, decisions, and real-time project activity.

## Branches

- `develop` is the integration branch.
- `main` is the release branch.
- Development happens on topic branches through pull requests.

## Development

Requirements: Node.js 24 (24.15.0 or newer) and npm 11 (11.12.1 or newer).

```sh
npm ci
npm run check
```

See [docs/development/WORKSPACE.md](docs/development/WORKSPACE.md) for setup details, root scripts, line endings, workspace layout, and package boundaries.
